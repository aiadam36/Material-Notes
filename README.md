# Material Notes

A lightweight, browser-based note-taking app styled with Material Design 3

## Features

- Create, edit, and delete notes
- Notes persist in the browser via localStorage
- Export all notes to a JSON backup file
- Import notes from a previously exported JSON file
- Notes are sorted newest-first

## Usage

Open `index.html` (or `app.html` directly) in any modern browser

To back up your notes, click the download button in the header. To restore, click the upload button and select a previously exported `.json` file
